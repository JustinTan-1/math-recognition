# Math Recognition

Chrome extention that predicts math symbols drawn on screen and allows you to copy them to clipboard. NOTE: Sometimes the backend takes some time to start up, just wait for around 30 seconds

DOWNLOAD HERE: https://microsoftedge.microsoft.com/addons/detail/mathrecognition/ikjbnaboopmnnlpojiokigccgiadbmgh
