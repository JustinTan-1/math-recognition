# Math Recognition

Chrome extention that predicts math symbols drawn on screen and allows you to copy them to clipboard.

<img width="300" alt="screenshot of app" src="./frontend/images/screenshot.png" />



# Instructions
- Download the repository files
- Go to "Manage Chrome Extensions" and click "Load Unpacked", navigate and select the front end folder
- Navigate to the root project directory
- Build the image using
```docker build -t imagename .```
- Run container with                             
```docker run -p 8000:8000 --name containername imagename```
